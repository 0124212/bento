# bento

My personal bento landing page — 12.log. One HTML file, zero frameworks, zero tracking, zero analytics, zero cookies. Just html, css, and a little js.

## Features

- Bento grid layout with cards (clock, goals, bookmarks, site stats, streak, uptime, learning)
- Light/dark theme + hidden themes (neon, vaporwave, miku, halloween, christmas, midnight)
- 45 hidden easter eggs — konami code, matrix rain, hidden commands, secret URL paths, and more
- Web Audio SFX, cursor trail, confetti, scroll-based card rotation
- Visitor counter + stats stored in localStorage
- Ko-fi support link

## Running

```bash
python -m http.server 8080
```

Or just open `index.html` in a browser. Deployed on Cloudflare Pages.

Type `help` on the page for commands. Konami code works. There's something at `#secret`.
